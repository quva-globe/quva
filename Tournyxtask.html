PHASE 3: TEAM 2 BACKEND

Supabase PostgreSQL Schema

  • profiles: Username, Rank, Power Level.
  • player_stats: Lethality, Endurance, Agility, Tactics, Perception.
  • player_telemetry: Kills, Damage, Accuracy.
  • adaptive_tasks: Dynamic quests and XP.
21

Securing the Web (RLS)

Web browsers expose API keys. Enforce Postgres Row-Level Security to prevent console tampering.

CREATE POLICY "Deny client-side stat updates" ON player_stats FOR UPDATE USING (false);
22

Cloudflare Edge Workers

  • Receives match telemetry POST requests directly from the browser.
  • Operates across 330+ global cities for <15ms latency.
